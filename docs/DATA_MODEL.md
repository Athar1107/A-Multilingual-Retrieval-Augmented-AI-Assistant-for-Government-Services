## 1. API Schemas ([`backend/app/schemas.py`](file:///c:/Users/athar/coding/model%20review/A%20Multilingual%20Retrieval-Augmented%20AI%20Assistant%20for%20Government%20Services/backend/app/schemas.py))

These Pydantic models govern request/response serialization and validation between clients and the FastAPI backend.

### `QueryRequest`
```python
class QueryRequest(BaseModel):
    text: str = Field(min_length=1, max_length=2_000)
    language: str = Field(
        default="en",
        description="ISO 639-1 language code for the query (e.g. 'en', 'kok')",
    )
```

### `SourceCitation`
```python
class SourceCitation(BaseModel):
    title: str
    source_url: str
```

### `QueryResponse`
```python
class QueryResponse(BaseModel):
    query: str
    answer: str
    confidence: float
    route: str = "direct"  # "direct" | "fallback" | "no_results"
    sources: list[SourceCitation]
```

## 2. Ingestion Document Models

### Processed English Corpus Document (`data/processed/active_english.json`)
The processed JSON document structure generated by [`app/services/ingestion.py`](file:///c:/Users/athar/coding/model%20review/A%20Multilingual%20Retrieval-Augmented%20AI%20Assistant%20for%20Government%20Services/backend/app/services/ingestion.py):

| Field | Type | Description |
|---|---|---|
| `doc_id` | `string` | Unique scheme slug (e.g. `"pmss"`, `"pg-igssgc"`, `"les-goa"`). |
| `title` | `string` | Official scheme title. |
| `source_url` | `string` | Canonical portal URL (e.g. `https://www.myscheme.gov.in/schemes/pmss`). |
| `content` | `string` | Cleaned descriptive text detailing eligibility, benefits, and requirements. |
| `metadata` | `object` | Key attributes including: |
| `metadata.issuing_body` | `string` | Ministry or government department name. |
| `metadata.tags` | `list[string]` | Keywords (e.g. `["education", "scholarship", "higher-education"]`). |
| `metadata.level` | `string` | Jurisdiction level (`"Central"`, `"State"`). |
| `metadata.collected_at` | `string` | ISO 8601 UTC collection timestamp. |
| `metadata.source_family` | `string` | Provenance label (`"myScheme"`). |

### Goa State PDF Document (`PdfDocument` in [`app/ingestion/pdf_loader.py`](file:///c:/Users/athar/coding/model%20review/A%20Multilingual%20Retrieval-Augmented%20AI%20Assistant%20for%20Government%20Services/backend/app/ingestion/pdf_loader.py#L49-L58))
Extracted from official circulars using PyMuPDF:

```python
@dataclass
class PdfDocument:
    doc_id: str             # e.g. "scert-goa-science-talent-search-2026"
    title: str              # Scheme or charter title
    source_url: str         # Direct PDF download URL
    content: str            # Cleaned, page-number-stripped text
    source_family: str      # "SCERT_Goa" | "DOL_Goa" | "Goa_Gov"
    category: str           # "scholarship" | "language_scheme" | "citizen_charter"
    date: str | None = None
    metadata: dict = field(default_factory=dict)
```

## 3. Vector Database Index Model (ChromaDB)

Stored persistently in `data/indexes/chroma/` under collection `education_schemes` (distance metric: cosine).

| ChromaDB Component | Type | Format / Content |
|---|---|---|
| `id` | `string` | Unique chunk ID: `{doc_id}_chunk_{j}` (e.g. `pmss_chunk_0`). |
| `document` | `string` | Chunk text (300 words chunk size, title prepended). |
| `embedding` | `list[float]` | 384-dimensional dense vector (`all-MiniLM-L6-v2`). |
| `metadata.scheme_id` | `string` | Parent `doc_id` linking chunks to their source record. |
| `metadata.title` | `string` | Official scheme title. |
| `metadata.source_url` | `string` | Canonical link for citation verification. |
| `metadata.chunk_index` | `integer` | 0-indexed position of chunk within the document. |
| `metadata.source_family`| `string` | `"myScheme"`, `"SCERT_Goa"`, `"DOL_Goa"`, or `"Goa_Gov"`. |

## 4. Retrieval & Rank Fusion Model ([`app/rag/retriever.py`](file:///c:/Users/athar/coding/model%20review/A%20Multilingual%20Retrieval-Augmented%20AI%20Assistant%20for%20Government%20Services/backend/app/rag/retriever.py))

Candidate passages returned by `retriever.retrieve(query, top_k)`:

```python
{
    "content": str,         # Chunk body text
    "title": str,           # Scheme title
    "source_url": str,      # Provenance URL
    "type": str,            # "dense" | "bm25"
    "rrf_score": float,     # Reciprocal Rank Fusion score (rounded to 6 decimals)
    "bm25_score": float,    # Raw BM25 score (present on BM25 candidates)
}
```

## 5. Fallback Routing Model ([`app/rag/fallback_routing.py`](file:///c:/Users/athar/coding/model%20review/A%20Multilingual%20Retrieval-Augmented%20AI%20Assistant%20for%20Government%20Services/backend/app/rag/fallback_routing.py))

Returned by `router.route(query, normalised_score, answer_text)`:

```python
{
    "route": "direct" | "fallback",
    "answer": str,          # Answer text (with caveat appended if route == "fallback")
    "confidence": float,    # Clamped normalized score in [0.0, 1.0] (rounded to 4 decimals)
}
```
